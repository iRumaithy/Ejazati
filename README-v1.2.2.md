# إجازاتي v1.2.2

## التعديلات

- التاريخ في الشريط العلوي أصبح ثابتًا بصيغة `dd/mm/yyyy`.
- اللون الأزرق في مفتاح التقويم أصبح «إجازة سنوية».
- العطلة الرسمية المتوقعة أصبحت بلون برتقالي/ذهبي فاتح بدل الأزرق.
- أسفل كل شهر في التقويم يظهر الآن «أحداث الشهر»:
  - العطلات الرسمية.
  - العطلات الخاصة.
  - الإجازات المسجلة للمستخدم.
- عند اختيار تاريخ بداية إجازة:
  - تاريخ النهاية ينتقل تلقائيًا إلى اليوم التالي.
  - يعمل الانتقال عبر نهاية الشهر ونهاية السنة، مثل 31/12 → 01/01.
- أسماء الشهور في بطاقات الإجازات أصبحت كاملة، مثل:
  - أغسطس
  - سبتمبر
  - نوفمبر
  بدل الاختصار.
- تحديث رقم الإصدار وسجل التحديثات إلى v1.2.2.
