# إجازاتي v1.2.8 — Stability Hotfix

## مهم
هذا الإصدار لا يحمّل `ui-v1.2.7.js` نهائيًا، لأن MutationObserver الموجود فيه كان يستطيع الدخول في حلقة تحديث ذاتية وتجميد Safari.

## ما تم إصلاحه
- عودة الصفحة للعمل وتحميل البيانات من Supabase.
- الساعة تعمل مرة أخرى وتتحدث كل ثانية.
- زر Refresh صغير في الشريط العلوي؛ وظيفته الوحيدة `location.reload()`.
- فحص تحديثات تلقائي كل 60 ثانية + عند العودة للتطبيق + عند عودة الإنترنت.
- يظهر إشعار داخل التطبيق عند نشر إصدار أحدث بدون Refresh.
- دعم Web Push خارج التطبيق عند تثبيت PWA ومنح الإذن مرة واحدة.
- عند نشر الإصدار من لوحة المالك يتم إرسال Push للمستخدمين المشتركين.
- إصلاح Changelog بدون MutationObserver متكرر.
- الاحتفاظ بإصلاح لون نص «مهمة / دورة».

## تم إعداد الخلفية بالفعل
- جدول Push Subscriptions تم إنشاؤه في Supabase.
- Edge Function لإرسال إشعار التحديث تم نشرها.
- بيانات الإجازات الحالية لم تُحذف.

## الملفات
1. `public/ui-v1.2.8.js` — جديد
2. `public/sw.js` — استبدال
3. `src/index.js` — استبدال
4. `package.json` — استبدال

لا تحذف ملفات v1.2.0 إلى v1.2.5، ولكن لا حاجة لتحميل v1.2.7 في `src/index.js`.

## ملاحظة الإنقاذ
v1.2.8 يفعّل Service Worker الجديد فور تثبيته لأنه Hotfix لتجمد v1.2.7. هذا خاص بهذه النسخة لإخراج الأجهزة من النسخة المعلقة.
