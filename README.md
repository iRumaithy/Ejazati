# إجازاتي

تطبيق شخصي Mobile-First لإدارة رصيد وإجازات الدوام.

## الهوية
الأيقونة المعتمدة: **الخيار رقم 2** — تقويم + شاطئ + نخلة + شمس.

## رفع المشروع إلى GitHub
1. أنشئ مستودعًا باسم `ejazati`.
2. ارفع **محتويات هذه الحزمة** إلى جذر المستودع، وليس مجلد `ejazati` نفسه.
3. افتح: `Settings` → `Pages`.
4. من `Build and deployment` اختر `Deploy from a branch`.
5. اختر `main` ثم `/ (root)` واضغط `Save`.

بعد النشر سيكون الرابط عادة:
`https://USERNAME.github.io/ejazati/`

## التثبيت على iPhone
افتح رابط GitHub Pages في Safari → مشاركة → **إضافة إلى الشاشة الرئيسية**.

## ملاحظة مهمة
الإصدار v1.0.0 يحفظ البيانات في `localStorage` على الجهاز نفسه.
وجود التطبيق على GitHub Pages يجعل الصفحة متاحة من أي جهاز، لكنه **لا يزامن البيانات بين الأجهزة**.
للمزامنة بين الآيفون واللابتوب سنربطه لاحقًا بـ Supabase وتسجيل دخول.

## الملفات
- `index.html` — التطبيق
- `manifest.webmanifest` — تعريف PWA
- `sw.js` — التخزين المؤقت والعمل دون اتصال
- `assets/icons/` — جميع مقاسات الأيقونة
- `.nojekyll` — توافق GitHub Pages
