# إجازاتي v1.2.0

هذه الحزمة هي **تحديث الواجهة فقط**. تغييرات Supabase المطلوبة لهذا الإصدار تم تنفيذها بالفعل على المشروع، لذلك **لا تشغّل أي SQL إضافي**.

## الجديد

- تسجيل الدخول باسم المستخدم أو البريد، مع بقاء الجلسة محفوظة.
- تاريخ ووقت الإمارات في الشريط العلوي مع الثواني وشعار إجازاتي.
- هوية بصرية عصرية: كحلي فاخر + ذهبي.
- رصيد سنوي مستقل لكل سنة:
  - في بداية السنة يُفتح الرصيد السنوي الكامل.
  - يضاف الرصيد المرحّل الصالح.
  - إجازات السنوات السابقة لا تخصم من السنة الجديدة.
- حقل «الرصيد المتاح حاليًا» لتصحيح الرصيد عند بدء استخدام التطبيق في منتصف السنة.
- تقويم عطلات الإمارات:
  - مواعيد مؤكدة تظهر كـ «مؤكدة رسميًا».
  - المواعيد الهجرية غير المؤكدة بعد تظهر كـ «متوقعة».
  - إمكانية تعديل التاريخ/الاسم أو تعطيل عطلة رسمية لحسابك فقط.
  - إمكانية إعادة العطلة إلى القيمة الأصلية.
- الإصدار الحالي v1.2.0 في أسفل الإعدادات.
- سجل تحديثات داخل التطبيق.
- تحسينات في النسخ الاحتياطي وتحديث التطبيق.

## الملفات التي ترفعها إلى GitHub

استبدل/أضف الملفات مع الحفاظ على المسار:

1. `public/ui-v1.2.0.js` — جديد
2. `public/sw.js` — استبدال
3. `public/manifest.webmanifest` — استبدال
4. `src/index.js` — استبدال
5. `package.json` — استبدال

لا تحذف `public/index.html` ولا `public/auth-hotfix.js` ولا مجلد `public/assets`.

## بعد الرفع

1. اعمل Commit إلى المستودع.
2. انتظر Cloudflare حتى ينتهي Deploy وتظهر الحالة ناجحة.
3. افتح إجازاتي.
4. عند ظهور «تحديث جديد جاهز» اضغط «تحديث الآن».
5. أغلق التطبيق وافتحه مرة أخرى.
6. من الإعدادات اضبط «الرصيد المتاح حاليًا» إذا كنت بدأت استخدام التطبيق في منتصف السنة.

## ملاحظة عن العطلات الرسمية

التواريخ الهجرية يمكن أن تتغير بحسب الإعلان الرسمي والرؤية الشرعية، لذلك يعرض إجازاتي حالة المصدر بوضوح، ويتيح لك تصحيح أي يوم لحسابك من دون تغيير التقويم لبقية المستخدمين.
