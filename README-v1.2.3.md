# إجازاتي v1.2.3

تحديث خاص بإصلاح ظهور المساحة البيضاء عند سحب التطبيق أكثر من أعلى أو أسفل الصفحة على iPhone / Safari.

## ما تم إصلاحه

- تثبيت خلفية `html` و`body` بنفس كحلي إجازاتي بدل خلفية WebKit البيضاء.
- إضافة طبقة خلفية داكنة احتياطية خلف مساحة التطبيق كاملة.
- منع Rubber-band / Overscroll عند:
  - أعلى الصفحة وسحبها لأسفل.
  - أسفل الصفحة وسحبها لأعلى.
- التمرير الطبيعي داخل الصفحات والنوافذ الطويلة يبقى يعمل.
- لا يؤثر الإصلاح على التنقل أو الأزرار أو حقول الإدخال.
- تحديث رقم الإصدار إلى v1.2.3.

## الملفات المطلوب رفعها إلى GitHub

1. `public/ui-v1.2.3.js` — ملف جديد
2. `public/sw.js` — استبدال
3. `src/index.js` — استبدال
4. `package.json` — استبدال

لا تحذف ملفات الإصدارات السابقة:
- `public/ui-v1.2.0.js`
- `public/ui-v1.2.1.js`
- `public/ui-v1.2.2.js`
- `public/auth-hotfix.js`
- `public/index.html`
- `public/assets/`

بعد نجاح Cloudflare Deploy:
1. افتح إجازاتي.
2. اضغط «تحديث الآن» إذا ظهر الإشعار.
3. أغلق التطبيق وافتحه مرة أخرى.
4. جرّب السحب لأعلى وأسفل بعد الوصول لنهاية الصفحة.
