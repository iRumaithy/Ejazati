# إجازاتي v1.1.1 — Hotfix

هذا التحديث يعالج:

- تعذر تحميل الحساب بعد تسجيل الدخول.
- إضافة اسم مستخدم فريد لكل حساب.
- تسجيل الدخول باسم المستخدم **أو** البريد الإلكتروني.
- بقاء الجلسة محفوظة على الجهاز وعدم طلب تسجيل الدخول مجددًا إلا بعد تسجيل الخروج.
- إضافة اسم المستخدم إلى شاشة الإعدادات.
- تحسين Service Worker حتى يجلب نسخة الواجهة الحديثة عند فتح التطبيق.

## ما تم بالفعل على الخادم

لا تشغّل ملفات SQL أو Edge Function يدويًا الآن:
- قاعدة Supabase تم تحديثها بالفعل.
- حساب المالك الحالي تم إصلاحه وتفعيله.
- Edge Function `ejazati-login` تم نشرها بالفعل.

الملفات داخل `supabase/` موجودة فقط لتوثيق GitHub ومزامنة الكود مع الخادم.

Cloudflare → Ejazati → Deployments → Deploy/Retry latest build.

## بعد ظهور العلامة الخضراء

1. افتح إجازاتي.
2. إذا ظهر إشعار تحديث، اضغط **تحديث الآن**.
3. أغلق التطبيق وافتحه مرة أخرى.
4. اختبر الدخول باسم المستخدم أو البريد.
